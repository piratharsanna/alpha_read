# AlphaRead

A cheerful, mobile-first alphabet learning app with an Instagram-inspired look. Tap any letter card to hear the letter and an example word spoken aloud using your browser's built-in text-to-speech.

## Run it

Open `index.html` in a modern browser, or publish the repository with GitHub Pages. No build step or external dependencies are required.

## Features

- Responsive, touch-friendly alphabet cards and story-style letter bubbles
- Spoken letter names and example words using the Web Speech API
- All, vowels, and heard-letter filters
- Learning progress, surprise letter, and reset controls
- Accessible button labels, keyboard focus styles, and reduced-motion support

Audio availability and voice quality depend on the browser and device.
